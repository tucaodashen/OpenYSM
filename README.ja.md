# OpenYSM

[简体中文](README.md) | [English](README.en.md) | **日本語**

![OpenYSM ロゴ](images/brand.png)

OpenYSM は、Minecraft 1.20.1 Forge 向け Yes Steve Model（YSM）2.6.5 をベースにしたオープンソース代替プロジェクトです。2026年4月の YSM 2.6.5 に対応するソースコードを含みます。

## 開発状況

**本番利用向けの安定版ではありません。** コードの命名や描画に問題が残る可能性があります。不具合はスクリーンショットとログを添えて Issue で報告してください。

## 機能と変更点

- モデルの読み込みと描画を Java で実装し、ネイティブコードへの依存を削減
- 既存の暗号化 YSM モデルに対応
- `/openysm cache dump` により受信済みモデルをデバッグ用に出力
- Ogg Opus 音声と WebP / AVIF テクスチャのデコード
- YSM と互換性のあるクライアント・サーバー間の通信とモデル描画

## 未完了の項目

- サブモデルのアニメーションコントローラー
- SIMD 描画最適化
- ハンドシェイク時のデフォルトモデル処理
- 古いバイナリ形式と非暗号化形式の互換性テスト
- YSGPHeader の生成
